# Comparative Hemoglobin Protein Analysis

## Project Overview
This project compares hemoglobin beta protein sequences from five different species using bioinformatics tools.

## Species Studied
1. Human
2. Chimpanzee
3. Mouse
4. Cow (Bovine)
5. Chicken

## Aim
To compare hemoglobin beta protein sequences and identify similarities and differences among five species.

## Tools Used
- UniProt – Protein sequence collection
- Clustal Omega – Multiple sequence alignment
- iTOL – Tree visualization

## Methodology
1. Retrieved protein sequences from UniProt in FASTA format.
2. Performed multiple sequence alignment using Clustal Omega.
3. Compared conserved and variable amino acid positions.
4. Visualized the Clustal Omega guide tree using iTOL.

## Expected Outcome
To understand protein sequence similarities and differences among the five species.
