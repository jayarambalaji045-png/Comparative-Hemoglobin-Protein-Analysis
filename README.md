Comparative Analysis of Hemoglobin Beta Protein Sequences Across Five Species

#1. Project Overview

Hemoglobin is an important protein found in red blood cells. Its main function is to transport oxygen from the lungs to different parts of the body.

This project compares hemoglobin beta protein sequences from five different species to understand their similarities and differences.

#2. Species Studied

1. Human
2. Chimpanzee
3. Mouse
4. Cow (Bovine)
5. Chicken

#3. Aim

To compare hemoglobin beta protein sequences from five species and identify similarities, differences, and evolutionary relationships.

#4. Objectives

- Retrieve protein sequences from UniProt.
- Perform multiple sequence alignment.
- Identify conserved and variable amino acid positions.
- Compare sequence similarities.
- Visualize the Clustal Omega guide tree.

#5. Tools Used

Tool| Purpose
UniProt| Protein sequence retrieval
Clustal Omega| Multiple sequence alignment
iTOL| Tree visualization

#6. Methodology

1. Retrieved five hemoglobin beta protein sequences from UniProt in FASTA format.
2. Submitted the sequences to Clustal Omega.
3. Performed multiple sequence alignment.
4. Compared conserved and variable amino acid positions.
5. Visualized the resulting guide tree using iTOL.

#7. Key Findings

- Human and chimpanzee sequences showed 100% identity in the alignment.
- Cow and mouse showed similarities with human hemoglobin beta.
- Chicken showed comparatively lower sequence identity with human hemoglobin beta.
- The Clustal Omega guide tree showed the grouping patterns among the five sequences.

#8. Project Files

- "sequences/" – Five FASTA protein sequences.
- "results/" – Multiple sequence alignment and tree files.
- "report/" – Project report in PDF and Word formats.

#9. Conclusion

The analysis demonstrates that hemoglobin beta protein sequences share similarities across different species. Multiple sequence alignment helps identify conserved regions and sequence variations.
